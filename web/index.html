Importar voos conferidos no site da Aena (CSV) Dados manuais, não ao vivo

Abra a página oficial da Aena, confira os dados que você pode utilizar e transcreva-os para CSV. Não há conexão automática, validação oficial ou atualização contínua. Os registros serão salvos no SQLite do Codespaces.

Colunas: flight_number,direction,scheduled_local,estimated_local,route,status,terminal. Para direction, use departure (partida) ou arrival (chegada).

Importar amostra manual em JSON Somente testes

Transcreva somente dados que você tenha autorização para usar. Os campos scheduled_local e estimated_local representam horários locais (HH:MM), não UTC. O importador não faz coleta automática da página oficial.

Fonte oficial para conferência: Aena Brasil — informações de voos Congonhas. A plataforma não tem integração oficial ativa; operações reais devem ser verificadas diretamente no operador.
